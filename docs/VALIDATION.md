## 可重现命令和边界

在干净克隆中执行 npm ci、npm test、npm run build。源码入口与完整安装流程见 INSTALL.md。可选真实模型测试从环境变量读取凭据，只发送合成内容；GUI 测试需另行配置可执行程序及隔离环境。

单元测试模拟 Obsidian API；它们不证明真实 GUI、移动端或同步行为。LiveSync 离线并发不保证分布式原子性。Templater 执行、手机日历和关闭应用后的后台任务均不在本版范围内。
